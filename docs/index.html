安 装 步 骤

  1. 下载完成后，在通知栏或「文件管理 → 下载」里点开安装包。
  2. 如提示「未知来源」，允许当前浏览器或文件管理安装应用。
  3. 打开本命兽，完成测验后点「让它去桌面」，按提示开启「显示在其他应用上层」。
  4. 开关是灰色、点不动？进入 设置 → 应用 → 本命兽，点右上角「⋮」选择「允许受限制的设置」，再回来打开。
